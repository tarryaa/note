# 余白 — YOHAKU

思考に、余白を。iPhone 15での使いやすさを考えた、日本語のメモアプリです。濃紺を基調に、半透明パネル、青とパープルの微発光、丸みのあるカードを組み合わせています。

HTML・CSS・JavaScriptだけで動きます。サーバー契約、ログイン、ビルド作業は不要です。GitHub Pagesで公開して、Safariやホーム画面から利用できます。

## 公開URL

[余白を開く](https://tarryaa.github.io/note/) — iPhoneのSafariで開き、共有メニューから「ホーム画面に追加」を選べます。

[ソースコード](https://github.com/tarryaa/note)

## できること

- メモの作成・編集・自動保存
- タイトルと本文の検索
- ピン留め、5色のコレクションと色別フィルター
- メモ数・ピン留め数・本文の文字数のダッシュボード
- グリッド表示・リスト表示と並べ替え
- ごみ箱への移動・復元・確認後の完全削除
- ダークを初期設定に、ライト・端末設定に合わせた表示も選択可能
- JSONファイルへのバックアップと読み込み
- 初回のオンライン読み込み後のオフライン利用

## GitHubにアップロードして使う

1. GitHubで新しいリポジトリを作成します。GitHub Freeの場合は **Public** を選びます。
2. ZIPを受け取った場合は先に展開し、中のファイルをリポジトリの直下にアップロードします。ZIPファイル自体をアップロードしてもアプリは動きません。`index.html`を別のフォルダーの中に入れないでください。`assets`フォルダーと、先頭にドットが付いた`.nojekyll`も含めます。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** で **Deploy from a branch** を選びます。
5. **Branch** を **main**、フォルダーを **/(root)** にして **Save** を押します。別のブランチにアップロードした場合は、そのブランチを選びます。
6. 公開処理が終わると、Pagesの設定画面にURLが表示されます。通常は `https://ユーザー名.github.io/リポジトリ名/` です。そのURLをiPhoneのSafariで開きます。

ファイルを更新したときも、同じ場所にアップロードします。公開前に`sw.js`の`VERSION`を新しい値（今回の`v2`から、次回は`v3`など）に変えてください。公開が完了したらアプリをオンラインで開き、「新しいバージョンが使えます」の「更新する」を押します。メモのバックアップファイルをリポジトリにアップロードする必要はありません。

設定の詳細は[GitHub公式の公開手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)を参照してください。

## iPhoneのホーム画面に追加する

1. 公開したURLを **Safari** で開き、最初の読み込みを完了させます。
2. Safariの **共有** を開きます。レイアウトによっては、ページメニュー内にあります。
3. **ホーム画面に追加** を選びます。
4. **ウェブアプリとして開く** が表示される場合はオンにし、**追加** を押します。
5. ホーム画面の「余白」アイコンから開きます。オフラインで使う前に、一度オンラインでアプリを開いてください。

Safariの画面や文言はiOSのバージョンによって異なります。[Apple公式のホーム画面への追加手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)も利用できます。

## メモの保存とバックアップ

メモは、その端末・ブラウザーの保存領域（localStorage）に保存します。GitHubにはアプリのファイルを置きます。**メモの内容はGitHubへ送信せず、端末間の自動同期も行いません。**

Safariとホーム画面のアプリ、別のブラウザーや端末では、同じ保存データを利用できるとは限りません。いつも使う開き方を決めておくと安心です。

設定からJSONバックアップを保存できます。別の端末へ移すときは、そのファイルを新しい端末で読み込みます。読み込みでは既存のメモを残し、同じIDのメモは更新日時が新しい方を採用します。ごみ箱のメモもバックアップに含まれます。

ブラウザーのサイトデータの消去、端末の初期化、保存領域の削除などでメモが失われることがあります。大切なメモは定期的にバックアップしてください。バックアップJSONには本文が含まれるため、自分で管理できる場所に保存します。

## パソコンで動作を確認する

Pythonが入ったパソコンで、このフォルダーを開いて実行します。

```powershell
python -m http.server 4173
```

ブラウザーで `http://localhost:4173/` を開きます。終了するときはターミナルで `Ctrl+C` を押します。

JavaScriptのモジュールを使っているため、`index.html`のダブルクリック（`file://`）では動作しません。Service Workerを使うオフライン機能は、GitHub PagesなどのHTTPS、または`localhost`で有効です。

Node.jsが入っている場合、保存処理のテストを実行できます。

```powershell
node --test tests/*.test.mjs
```

iPhone 15相当の393×852の画面幅と、パソコンでの表示に対応しています。パソコンでは左サイドバー、iPhoneでは下部ナビゲーションで操作できます。iPhone実機での検証は行っていません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリの画面 |
| `styles.css` | iPhone・パソコン向けの表示 |
| `app.js` | メモの操作と画面の更新 |
| `store.js` | メモの保存・バックアップの検証 |
| `manifest.webmanifest` | ホーム画面アプリの設定 |
| `sw.js` | オフライン用のキャッシュ |
| `assets/` | アプリのアイコン |
| `.nojekyll` | GitHub Pagesでそのまま配信する設定 |
| `tests/` | 保存処理の自動テスト |

端末への保存を中心にした個人用アプリです。実際のiPhoneで、入力・画面の回転・ホーム画面からの起動・機内モードでの起動を確認してから使い始めてください。
